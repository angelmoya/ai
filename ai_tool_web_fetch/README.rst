AI Tool Web Fetch
=================

This module adds a ``web_fetch`` tool to the AI Tool framework. The tool allows language models to fetch the content of any URL during a conversation, enabling web research, API queries, and content retrieval.

**Table of contents**

.. contents::
   :local:

Configuration
=============

No additional configuration needed. This module depends on ``ai_tool``.

Usage
=====

Once installed, the ``web_fetch`` tool is automatically available to any AI connection that has tools enabled. The tool accepts a single ``url`` parameter and returns the page content as text.
