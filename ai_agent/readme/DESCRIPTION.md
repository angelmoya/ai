# AI Agent

This module introduces autonomous AI agents on top of the OCA AI stack.

An agent combines:

- A **goal** and a reusable **soul** (personality, voice, values)
- Behavioural **protocols**
- Reusable **skills** and **tools**
- A default **connection** plus optional connection routing rules
- Per-user **threads** with conversation history
- Visible, approvable **plans**
- Scheduled **jobs**

Agents can run simple prompts or plan multi-step tasks before executing them.
